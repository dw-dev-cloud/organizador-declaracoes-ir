# 🧙‍♂️ Wizard App - Organizador de Declaração de Imposto de Renda

## 📌 Sobre o Projeto
O **Wizard App** é uma planilha inteligente desenvolvida durante o curso **"Criando Um Organizador de Declaração de Imposto de Renda"** na plataforma **DIO (Digital Innovation One)**,Projeto desenvolvido sob a orientação do instrutor [@felipeAguiarCódigo](https://github.com/felipeAguiarCodigo) durante o bootcamp de Excel Avançado da DIO.

O projeto simula um software de gestão financeira pessoal, superando as limitações do Excel Web através de soluções criativas em formatação avançada, navegação por hiperlinks e visualização de dados integrada.

## ✨ Funcionalidades
- **Navegação Intuitiva:** Menu lateral fixo com botões "PRÓXIMO >>" e "<< ANTERIOR" que funcionam como links entre abas (TITULAR, INFORMES, NOTAS), simulando a experiência de um aplicativo real.
- **Formatação Avançada:** Máscaras automáticas para CPF (`000.000.000-00`), Telefone (`(00)00000-0000`) e CEP, garantindo padronização dos dados.
- **Dashboard Financeiro:** Aba "INFORMES" com soma automática de rendimentos bancários (Total: R$ 5.169.676,00) e formatação condicional em moeda (R$).
- **Gestão de Entradas:** Tabela estruturada na aba "NOTAS" para registro de receitas por categoria (HOLERITE, CNPJ, FREELANCE) com gráfico dinâmico integrado.
- **Base de Dados:** Aba "TABELA" com lista completa de códigos bancários brasileiros para consulta rápida.

## 🛠️ Tecnologias e Ferramentas
- Microsoft Excel Web (Office 365)
- Formatação Personalizada (Máscaras de Input)
- Hiperlinks Internos (Navegação entre Sheets)
- Validação de Dados e Listas Suspensas
- Gráficos Dinâmicos Integrados
- *Conhecimentos aplicados:* Excel Intermediário/Avançado, Análise de Dados, Automação Básica

##  Contexto de Aprendizado
Este projeto foi desenvolvido como atividade prática do bootcamp **[NOME DO BOOTCAMP/CURSO]** da **DIO**, demonstrando a aplicação de conceitos de Excel Avançado em um cenário real de organização financeira e declaração de impostos.

## 🚀 Como Usar
1. Baixe o arquivo `wizard-app-ir.xlsx`.
2. Abra no Microsoft Excel (Desktop ou Web).
3. Utilize o menu lateral roxo à esquerda para navegar entre as seções.
4. Preencha os dados nas células amarelas/roxas conforme solicitado.
